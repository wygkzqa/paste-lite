如何安装？支持哪些 Mac？

需要 macOS 14 或更新版本。前往 最新正式版 下载 Universal DMG，一个安装包同时支持 Apple Silicon 与 Intel。

打开 DMG，将 Paste Lite 拖到“应用程序”，再从那里启动。应用常驻菜单栏，默认按 ⇧⌘V 打开历史。

首次打开被 macOS 阻止怎么办？

目前应用使用临时签名，尚未经过 Apple 公证。确认信任本项目并核对下载后，请参考 Apple 关于打开身份未验证应用的说明。应用内更新签名不替代 Apple 公证。

为什么没有自动粘贴到原应用？

自动粘贴需要在“系统设置 → 隐私与安全性 → 辅助功能”中授权。当前存在系统开关已开启但应用仍判断未授权的已知问题，替换构建也可能使旧授权失效。

未授权时仍会复制到系统剪贴板，切回目标应用后手动按 ⌘V 即可。详见 权限说明。

剪贴板内容会上传吗？是否加密？

剪贴板历史保存在本机，无需账号，不提供云同步，也不收集遥测数据。本地数据未经应用加密；跳过机密等剪贴板标记，并不意味着能识别所有密码或密钥。

主动检查或下载更新会访问 GitHub，但请求不包含剪贴板内容；自动检查默认关闭。本网站由 GitHub Pages 托管，GitHub 会记录访问者 IP 用于安全目的，见 托管服务说明。

文件记录和 Paste 导入有什么限制？

文件记录保存路径引用，不是文件备份。原文件移动或删除后，该记录可能无法继续使用。

导入目前针对 Paste 6.0.3 的本地数据结构验证。仅在云端的内容、缺失附件和不支持的格式会跳过，富文本样式不会保留。详见 导入范围与步骤。

如何更新？需要付费吗？

Paste Lite 免费开源，采用 MIT 许可证。1.1.1 及后续版本可在菜单栏或“设置 → 关于”中检查更新，下载与安装由你确认；自动检查默认关闭。也可以随时从 GitHub Releases 下载正式版。
