A few things to know

Before you get started.

A clear look at installation, everyday use and your data.

How do I install it? Which Macs are supported?

You need macOS 14 or later. Download the Universal DMG from the latest release. One package supports both Apple Silicon and Intel.

Open the DMG, drag Paste Lite to Applications, then launch it from there. The app lives in the menu bar. Press ⇧⌘V to open your history.

What if macOS blocks the first launch?

The app currently uses ad-hoc signing and is not notarized by Apple. After verifying the download and deciding that you trust this project, follow Apple’s instructions for opening an unidentified app. The in-app update signature does not replace Apple notarization.

How do I use a history item in another app?

Double-click an item, press Return, or choose Copy to Clipboard in its preview to write it to the clipboard. The panel closes and returns focus to your previous app, where you press ⌘V to paste.

Paste Lite does not need Accessibility permission or send paste keystrokes automatically.

Is my clipboard uploaded? Is it encrypted?

History is stored on your Mac. There is no account, cloud sync or telemetry collection. Local data is not encrypted by the app. Skipping confidential clipboard markers does not mean every password or secret can be detected.

Checking for or downloading updates contacts GitHub without sending clipboard content; automatic checks are off by default. This website is hosted on GitHub Pages, which logs visitor IP addresses for security. See the hosting documentation.

Are there limits to file history and Paste import?

File entries store references to original paths, not backups. Moving or deleting the original file may make an entry unusable.

The importer is validated against Paste 6.0.3’s local data structure. Cloud-only content, missing attachments and unsupported formats are skipped. Rich-text formatting is not preserved. See the import guide for details.

How do updates work? Is it free?

Paste Lite is free and open source under the MIT license. Version 1.1.1 and later can check for updates from the menu bar or Settings → About. You confirm downloads and installation; automatic checks are off by default. You can also download releases directly from GitHub.
