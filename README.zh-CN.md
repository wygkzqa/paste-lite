## 关于

Paste Lite 常驻 macOS 菜单栏，让复制过的内容随时可用。按下 **⇧⌘V**，找到需要的记录，即可在当前应用中再次使用。

应用使用 SwiftUI、AppKit 和 SwiftData 构建，历史记录保存在本机，无需账号，不提供云同步，也不收集遥测数据。应用界面与项目文档均提供英文和简体中文版本。

## 功能

- **剪贴板历史** — 保存纯文本、链接、图片和文件引用，相同内容自动去重。
- **从 Paste 导入** — 扫描本机 Paste 历史，确认数量与容量后批量导入支持的内容及 Pinboard 分组，保留原始时间和来源应用。
- **快速搜索** — 搜索内容、文件名和来源应用，并按内容类型、应用筛选。
- **图片预览** — 显示图片缩略图，按需打开预览查看图片、文本、链接或文件路径。
- **快捷键操作** — 使用 ⇧⌘V 打开历史，通过方向键选择，用 ⌘1–9 快速使用前九条结果。
- **返回原应用** — 双击记录或按 Return，将内容复制并尝试粘贴到原应用；自动粘贴需要辅助功能权限。
- **原生界面** — 常驻菜单栏、不占用 Dock，跟随系统明暗外观，时间标签按打开面板时的时间基准计算并缓存。
- **两种紧凑布局** — 在设置中切换列表与卡片；macOS 26 使用系统原生液态玻璃，旧版系统使用半透明材质。
- **分组管理** — 创建、重命名分组，将记录加入多个分组，并在分组内搜索；删除分组会保留历史记录。
- **开机启动** — 在设置中按需开启，由 macOS 登录项管理。
- **语言设置** — 默认跟随系统，也可手动选择简体中文或 English；即时生效并记住选择。
- **本地存储** — 历史记录和采集的图片保存在磁盘中，电脑睡眠或用户会话不活跃时暂停监测。

单个图片文件也会出现在“图片”分类中，重新复制时仍保留文件形式。

## 开始使用

### 环境要求

- 运行应用需要 macOS 14 或更新版本。
- 构建需要 Xcode 26 或更新版本，用于编译原生 `.icon` 图标资源。

### 从源码构建

下载或克隆本仓库，在项目根目录执行：

```bash
xcodebuild \
  -project PasteLite.xcodeproj \
  -scheme PasteLite \
  -configuration Release \
  -derivedDataPath .build \
  build

open ".build/Build/Products/Release/Paste Lite.app"
```

如需安装，先退出正在运行的 Paste Lite，再通过 Finder 将 `.build/Build/Products/Release/Paste Lite.app` 复制到**应用程序**目录，启动安装后的应用。开发和测试方式见[贡献指南](./CONTRIBUTING.zh-CN.md)。

### 使用方式

| 操作 | 快捷键或交互 |
| --- | --- |
| 打开 / 关闭历史列表 | ⇧⌘V 或菜单栏菜单 |
| 打开主界面 | 从 Spotlight 或 Finder 打开 Paste Lite |
| 选择记录 | 单击或 ↑ / ↓ |
| 多选记录 | ⌘单击增减选中项；⇧单击或 ⇧↑ / ⇧↓ 连续选择 |
| 全选筛选结果 | 历史区域获得焦点时按 ⌘A，或右键 → 全选 |
| 删除所选记录 | 右键 → 删除…，然后确认 |
| 复制并尝试粘贴记录 | 双击或 Return |
| 使用筛选结果中的前九条记录 | ⌘1–9 |
| 关闭面板 | Esc |
| 预览选中内容 | 右键记录 → 预览 |
| 切换布局 | 主界面底部布局按钮，或设置 → 通用 → 剪贴板布局 |
| 创建或管理分组 | 分组菜单 → 新建分组… / 管理分组 |
| 打开设置 | 菜单栏 → 设置…，或在 Paste Lite 激活时按 ⌘, |

从 Spotlight 或 Finder 打开 Paste Lite 会显示主界面，应用已在运行时也一样。开机启动仍仅常驻菜单栏，不主动弹出面板。

选择记录不会触发粘贴。上下方向键选择时会滚动以保持选中项可见，鼠标点击不会让列表自动滚动。未获得辅助功能权限时，粘贴操作仍会把记录写入系统剪贴板；切回目标应用后，手动按 **⌘V** 即可。

### 布局与分组

在 **设置… → 通用 → 剪贴板布局** 中选择 **列表**（默认）或 **卡片**，也可使用主界面底部的布局按钮直接切换，保留搜索、筛选、分组和选中记录。选择即时生效并自动保存，与设置同步。两种布局共用历史、搜索、筛选和快捷键，玻璃外观跟随系统明暗及“减少透明度”设置。

在 **通用** 中开启 **渐变背景**，即可为两种布局的面板内部添加柔和渐变。默认关闭，切换立即生效并记住选择；颜色适配浅色与深色模式，开启“减少透明度”时使用不透明渐变。

关闭渐变时，选中记录显示蓝色背景与白色文字；开启渐变时保留半透明玻璃高亮，两种布局保持一致。

通过分组菜单创建分组，在 **管理分组** 中重命名或删除。右键 **加入分组** 会直接展开二级菜单，底部 **分组** 也可直接选择已有分组。勾选表示全部所选记录已加入，横线表示部分记录已加入；点击未勾选或部分加入的分组会统一加入，点击已勾选的分组会移除归属。**新建分组…** 创建后会加入所选记录。同一条记录可加入多个分组，不重复保存内容。固定提供 **全部历史** 与 **未分组**，搜索及类型、来源筛选作用于当前分组。删除分组只移除归属关系；分组记录仍参与现有保留天数和条数规则的清理。

### 设置分类

设置使用左右两列：左侧选择**通用、历史、数据、关于**，右侧显示对应选项。通用集中语言、剪贴板布局、渐变背景、开机启动，以及管理单条收录大小的采集配置；历史管理保留和清理规则；数据提供 Paste 导入与清空历史；关于显示 Logo、版本、构建号和 GitHub 入口。菜单栏的 **关于 Paste Lite** 会打开同一个设置窗口并切换至关于页。

### 界面语言

打开**设置… → 通用 → 语言**，选择**跟随系统**、**简体中文**或 **English**。默认跟随系统：系统首选语言为中文（包括繁体地区）时使用简体中文，其他语言使用英文。切换后整个应用界面立即更新，无需重启，也不会修改剪贴板正文、文件名、来源应用名称或历史记录。设置会自动保存。

### 开机启动

打开**设置… → 通用 → 开机启动**，即可在登录 Mac 后自动打开 Paste Lite，默认关闭。开关读取 macOS 登录项状态，在打开设置或返回应用时刷新。如果需要系统允许，点击**打开登录项设置…**进行确认；设置失败时显示错误并保留系统实际状态。建议先将应用安装到 Applications。

### 收录与历史限制

**设置… → 通用 → 采集**可调整文本和图片最大收录大小。等于上限时允许收录，超过则跳过。修改只影响之后的采集和导入，不会删除已有大记录。

**设置… → 历史**可调整保留天数、最大条数和清理周期（小时）。三项默认均为 0，分别表示永久保留、不限条数和关闭周期清理。启动时仍会检查一次保留规则；修改设置不会立即删除记录，两次清理之间可以暂时超过条数上限。清理以创建时间而非最近使用时间为准，先删除过期记录，再保留条数上限内最新的记录。

历史在数据库中查询，每页读取 200 条摘要，预览或粘贴时按需读取正文。搜索覆盖全部历史，包括尚未加载的页面。目前使用子串查询，没有全文索引，大量长文本的搜索仍可能耗时。

### 清空历史

在**设置… → 数据 → 清空历史…**中确认后，永久删除 Paste Lite 全部历史（包括分组内记录）、图片、缩略图及旧版迁移备份。分组和设置保留；系统当前剪贴板及文件记录指向的原始文件不受影响。此操作不可撤销。清空完成后，新复制的内容仍会正常收录；图片文件清理失败会明确提示，可再次清空重试。

### 多选与删除记录

⌘单击增减选中项，⇧单击连续选择。右键已选中的记录会保留多选，右键未选中的记录则只选中该条。⌘A 全选当前搜索、类型、来源和分组筛选下的全部结果，包括尚未加载的页面，不加载完整正文。搜索框或编辑表单获得焦点时，⌘A 保留原生文字全选行为。切换筛选会清除之前的选择。

通过右键 **删除…**，确认记录数量后删除。记录会从全部历史及所有分组中移除，并清理不再被其他记录使用的图片和缩略图；保留分组定义、设置、系统当前剪贴板和外部原文件。删除无法撤销。编辑和预览仅在选中单条记录时可用。

### 编辑与预览记录

右键列表项或卡片会先选中对应记录，再打开菜单。**编辑…**和**预览**共用包含标题、内容的表单，预览为只读。文本和链接支持编辑正文；图片和文件支持修改标题，保留原内容。⌘Return 保存，正文中的 Return 换行，Esc 取消。保存只更新历史，复制或粘贴记录时才会写入系统剪贴板。

新标题最多 100 个字符且不能换行，清空可恢复自动标题；仅修改正文时可以保留从 Paste 导入的长标题。标题显示在两种布局和预览中，参与全库搜索。编辑保留记录 ID、时间、排列、来源和分组，正文修改同步更新摘要和去重依据。空文本、无效链接、超出设置大小限制的文本及与其他记录重复的内容不能保存，错误时保留输入。再次复制编辑后的内容时保留标题。

### 从 Paste 导入

1. 等待 Paste 下载完需要迁移的历史，然后退出 Paste。
2. 打开**设置… → 数据 → 从 Paste 导入 → 导入…**。如未自动找到数据，选择包含 `db.sqlite` 及 `.db_SUPPORT` 附件的数据文件夹。
3. 点击**扫描数据**，查看可新增、重复、无法导入的数量，以及所需容量。
4. 点击**导入 N 条**。默认不限条数；如果自行设置了条数上限，可选择**提高条数上限并导入全部**，或仅导入剩余条数内的最近记录。

当前识别已针对 **Paste 6.0.3** 验证的本地数据结构，其他结构会提示暂不支持。导入器读取数据库快照，不修改源数据库和附件。整个过程在本机完成，不需要辅助功能权限、不联网，也不会写入系统剪贴板；不会持续同步两个应用。

支持文本、链接、PNG/TIFF/JPEG 图片和有效文件引用。RTF 转为纯文本；HTML 需要附带纯文本表示。保留标题、Pinboard 名称（包括空分组）和记录归属。Paste 中相同内容有不同标题时，采用最近的非空标题；导入标题完整保留，包括超过手工编辑 100 字上限的标题。同名分组不区分大小写合并。同一内容出现在多个 Pinboard 中时，保留全部归属而不重复存储正文。不保留分组和记录排序、置顶、共享关系和富文本样式。仅在云端的内容、缺失附件、失效文件和不支持的格式会计入跳过原因，不会把预览图冒充原图导入。

与已有内容重复时，保留原记录的 ID、时间、来源及本地分组，只补充缺少的分组归属和标题，已有本地标题优先。全部内容已存在或历史条数已满时，也可点击**导入分组与标题**补充组织信息。每次导入按名称匹配分组，因此在本地重命名后再次导入，可能会按原名创建分组。导入不会为了腾空间而删除已有历史。提高后的条数上限在重启后仍有效。导入记录也受保留周期约束，按原始创建时间参与后续清理。收录大小限制变化后需要重新扫描。最终保存前可以取消扫描，重复导入不会新增重复记录。

## 辅助功能权限

点击历史面板中的**打开设置**，或前往**系统设置 → 隐私与安全性 → 辅助功能**，开启 Paste Lite 的权限。如果列表中没有应用，点击 **+** 添加 `/Applications/Paste Lite.app`。

**已知问题：**系统开关已经开启时，应用仍可能显示“未授权”，目前尚未解决。重启应用，或移除后重新添加安装版本可能有帮助，但不是已确认有效的修复。项目目前使用临时签名，替换构建也可能使旧授权失效。仍可使用复制后手动按 ⌘V 的方式。

## 数据与隐私

历史记录位于 `~/Library/Application Support/PasteLite/`。文件记录只保存原始路径引用，不会备份文件；原文件被移动或删除后，对应记录可能无法继续使用。

- 每两秒检查一次剪贴板，因此快速连续复制的内容不一定全部被记录。
- 默认不限历史条数、永久保留、不限制总存储容量。收录和清理配置保存在 `history-settings.json`。旧 `limits.json` 的额度不再生效，升级保留已有历史。
- 文本和链接默认每条 4 MB，保存的 PNG 图片默认每张 100 MB；均可调整，0 表示不限。MB 按 1024 × 1024 字节计算。文件引用不复制文件，也不按原文件体积限制收录。
- 忽略标记为机密、临时或自动生成的剪贴板内容，不会自动识别未标记的密码等敏感文本。
- 数据仅保存在本机，但应用不会对其加密，请像其他个人文件一样妥善保护。
